# OneCity logos

Brand assets are grouped by use case:

- `onecity-logo.svg`: primary horizontal logo for headers, footers, and brand lockups.
- `onecity-mark.svg`: standalone symbol for compact UI placements.
- `onecity-logo.png`: raster fallback generated from the primary SVG when PNG output is required.

Prefer SVG in the app UI so the logo stays sharp on high-density screens.
